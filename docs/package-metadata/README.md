# Branding im Contao Manager

Titel, Beschreibung und Logo in der Paketliste des Contao Managers kommen nicht aus Packagist,
sondern aus dem Repository [contao/package-metadata](https://github.com/contao/package-metadata).

Die Dateien in diesem Ordner sind für diesen Pull Request vorbereitet. Prüfe vor dem Einreichen
den Aufbau anderer Pakete dort (`meta/<vendor>/<paket>/`) und die Vorgaben zum Logo, und passe
die Dateien bei Bedarf an:

```
meta/derkosmonaut/tourtimes-contao/de.yml
meta/derkosmonaut/tourtimes-contao/en.yml
meta/derkosmonaut/tourtimes-contao/logo.svg
```
